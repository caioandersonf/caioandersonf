### 💻 Projeto em Destaque

#### [⚡ Clock Máximo — E-commerce & PC Builder](https://github.com/caioandersonf/clock-maximo)
Plataforma e-commerce completa especializada em peças de computador e montagem de PCs de alto desempenho.
- **Stack**: Laravel 11 (PHP 8.2+), Vue.js 3, Inertia.js, TailwindCSS, MariaDB / SQLite.
- **Principais Recursos**:
  - **PC Builder**: Wizard dinâmico com matriz de compatibilidade EAV (Socket/RAM) e emissão de orçamento técnico limpo para impressão/PDF.
  - **Mercado Pago API**: Pagamento via PIX com 15% OFF, QR Code/Copia e Cola e Webhook em tempo real.
  - **Cálculo de Frete**: Integração com API Correios (PAC e SEDEX) e rastreamento automatizado.
  - **Passwordless OTP**: Login sem senha via código único enviado por e-mail.
  - **Upload Nuvem**: Upload de imagens de produtos direto no Cloudflare R2 Storage.
