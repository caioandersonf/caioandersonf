    ### 💻 Projeto em Destaque / Featured Project
    
    #### [⚡ Clock Máximo — Plataforma E-commerce & PC Builder](https://github.com/caioandersonf/clock-maximo)
    E-commerce de altíssimo desempenho para peças de computador e montagem inteligente de PCs Gamer.
    - **Stack**: Laravel 11 (PHP 8.2+), Vue.js 3, Inertia.js, TailwindCSS.
    - **Destaques**:
      - **PC Builder Inteligente**: Wizard interativo com filtragem dinâmica de compatibilidade (Socket/RAM via
  modelagem EAV) e emissão de orçamento técnico para impressão/PDF.
      - **Checkout Mercado Pago API**: PIX instantâneo com 15% de desconto, QR Code e Webhook de pagamento em tempo
  real.
      - **Frete Correios**: Cálculo de PAC/SEDEX em tempo real via API oficial e e-mail automático com rastreamento.
      - **Autenticação Passwordless**: Login sem senha com envio de código único OTP por e-mail.
      - **Upload Nuvem**: Armazenamento de imagens integrado ao Cloudflare R2 (S3 API).
